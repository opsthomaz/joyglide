# ── Windows only ─────────────────────────────────────────────────────────
# Note: we DO NOT depend on `winsdk` here. bleak already pulls in
# `winrt-Windows.Devices.Bluetooth` (the older `winrt-runtime` projection).
# Mixing the two projections (winrt + winsdk) breaks the marshaller because
# their Python types are distinct even when they wrap the same WinRT class —
# the call would fail with "TypeError: convert_to returned null". So
# platform_setup.py imports BluetoothLEPreferredConnectionParameters from
# `winrt`, matching what bleak already uses internally.

# ── Linux only ───────────────────────────────────────────────────────────
# evdev drives the kernel-level uinput cursor injection (osio/mouse/linux.py)
# AND the Ctrl+Alt+M global hotkey listener (osio/hotkey/linux.py). Same
# library coffincolors/jc2mouse uses — well-tested, widely-shipped, no
# transitive baggage. Membership in the `input` group + the standard udev
# rule on /dev/uinput is the runtime requirement.
evdev>=1.9.3; sys_platform == 'linux'
